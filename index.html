Updating Photos & Specs Permanently

  1. Create a folder named images next to this index.html file.
  2. Place your HOD's real photos inside (for example: 1way-installed.jpg).
  3. Open index.html in any text editor and update the images fields inside UNITS_DATA:
images: {
  installed: "images/1way-installed.jpg",
  closeup:   "images/1way-closeup.jpg",
  airflow:   "" // leave empty to keep built-in diagram
}

Leaving any image field as "" automatically displays the built-in architectural SVG illustration—so there are never broken images.
